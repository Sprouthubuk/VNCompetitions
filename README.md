# Vault Nine Competitions

The rebuild of vaultninecompetitions.co.uk: an Astro storefront on a Laravel API, deployed with Laravel Forge.

| Folder | What's in it |
|---|---|
| `web/` | Astro storefront (SSR). Design done; runs on sample data or the API. |
| `api/` | Laravel 12 API + Filament admin (to be created, see build plan). |
| `docs/` | Build plan, API contract, product decisions, Forge setup, Lovable audit. |

Start here: `CLAUDE.md`, then `docs/BUILD_PLAN.md`.

```bash
cd web && npm install && npm run dev   # http://localhost:4321
```
